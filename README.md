
### 📋 **Project Overview**
- Modern portfolio website 
- Software developer showcasing skills and experience
- Responsive design with dark/light mode

### ⭐ **Key Features**
- Dark/Light mode toggle with saved preferences
- Fully responsive (mobile, tablet, desktop)
- Modern, clean UI/UX design
- Accessibility-focused (WCAG compliant)
- Fast performance with no external dependencies

### 🛠️ **Tech Stack**
- **HTML5** - Semantic structure
- **CSS3** - Variables, flexbox, responsive design
- **JavaScript** - Theme toggle functionality
- **Three.js** - Animated 3D hero scene (`assets/js/hero-3d.js`), loaded from a CDN; respects reduced-motion and falls back to the 2D design without WebGL

### 📱 **Responsive Design**
- Mobile: < 600px
- Tablet: 601px - 1024px  
- Desktop: > 1025px

### 🎨 **Design Features**
- **Light Theme**: White background, dark text, blue accent
- **Dark Theme**: Dark background, light text, lighter blue accent
- Professional typography using system fonts

### 🚀 **Quick Setup**
1. Download all files to a folder
2. Open `index.html` in any browser
3. Or use local server: `python -m http.server 8000`

### ⚙️ **Customization**
- Update personal info in HTML
- Replace profile image URL
- Modify company logos
- Change colors in CSS variables

### 🌐 **Browser Support**
- Chrome 60+, Firefox 55+, Safari 12+, Edge 79+
